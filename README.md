# 🏥 Hospital Management System

## Database Management Systems Cornerstone Project

A Hospital Management System developed using **Oracle SQL** to manage patients, doctors, departments, appointments, medical records, prescriptions, rooms, and bills.

## 🎯 Objectives

- Manage hospital information in a structured database.
- Store and retrieve patient and doctor details.
- Manage appointments and medical records.
- Maintain prescription, room, and billing information.
- Ensure data accuracy and integrity using database constraints.

## 🗂️ Database Entities

The system contains 8 entities:

- Patient
- Doctor
- Department
- Appointment
- Medical Record
- Prescription
- Room
- Bill
